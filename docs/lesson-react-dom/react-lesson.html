React គឺអ្វី?

React គឺជា JavaScript library សម្រាប់បង្កើត UI ដោយបំបែក UI ជា Components។ Component មួយអាចតូចដូច button ឬធំដូច page ទាំងមូល។ ក្នុង React, component ជា JavaScript function ដែល return markup/JSX។

function MyButton() {
  return <button>Click me</button>;
}

export default function App() {
  return (
    <div>
      <h1>Hello React</h1>
      <MyButton />
    </div>
  );
}
ចំណុចបង្រៀន: React មិនគិតជា "page first" ទេ។ React គិតជា "component first"។ UI ធំ = component តូចៗច្រើនបញ្ចូលគ្នា។

Displaying Data

JSX ប្រើ {} ដើម្បីចូលទៅ JavaScript expression — text, attributes, calculation, string concatenation ក្នុង JSX ទាំងអស់।

const user = {
  name: 'Nha',
  imageUrl: '/avatar.png',
  imageSize: 100,
};

function Profile() {
  return (
    <>
      <h1>{user.name}</h1>
      <img
        src={user.imageUrl}
        alt={'Photo of ' + user.name}
        style={{ width: user.imageSize, height: user.imageSize }}
      />
    </>
  );
}
ចំណុចបង្រៀន: "/avatar.png" = string fixed  ·  {user.imageUrl} = value ពី JavaScript

Conditional Rendering

React ប្រើ JavaScript ធម្មតា — if, ternary ? :, ឬ && — គ្មាន syntax ពិសេសទេ។

// if statement
function Dashboard({ isLoggedIn }) {
  if (isLoggedIn) return <AdminPanel />;
  return <LoginForm />;
}

// ternary
function Dashboard({ isLoggedIn }) {
  return <div>{isLoggedIn ? <AdminPanel /> : <LoginForm />}</div>;
}

// && short-circuit
function Notification({ hasNewMessage }) {
  return (
    <div>{hasNewMessage && <p>You have new messages</p>}</div>
  );
}

Rendering Lists

React ប្រើ map() ដើម្បីបម្លែង array ទៅ JSX list។ ក្នុង list ត្រូវមាន key ពិសេសសម្រាប់ item នីមួយៗ។

const products = [
  { id: 1, title: 'Laptop' },
  { id: 2, title: 'Mouse' },
  { id: 3, title: 'Keyboard' },
];

function ProductList() {
  return (
    <ul>
      {products.map(product => (
        <li key={product.id}>{product.title}</li>
      ))}
    </ul>
  );
}
⚠️ កុំប្រើ index ជា key ប្រសិនបើ list អាច reorder/delete ប្រើ database id ឬ unique id ពី data ជំនួស។

Events

React event handler គឺ function ដែល pass ទៅ event prop ដូចជា onClick។ Pass function — មិន call function។

❌ ខុស — call function ភ្លាម 
<button onClick={handleClick()}>Click</button>
✅ ត្រូវ — pass function reference 
<button onClick={handleClick}>Click</button>
function Button() {
  function handleClick() {
    alert('Clicked');
  }
  return <button onClick={handleClick}>Click</button>;
}

State និង useState

State គឺ memory របស់ component។ useState ផ្តល់ current state និង setter function — convention [something, setSomething]។

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <button onClick={handleClick}>
      Clicked {count} times
    </button>
  );
}
ចំណុចបង្រៀន: ពេល setCount() ត្រូវបាន call, React render component ម្តងទៀត → UI ផ្លាស់ប្តូរតាម state ថ្មី។

Lifting State Up

ពេល components ច្រើនត្រូវការ state ដូចគ្នា → lift state ទៅ parent ដែលនៅជិតបំផុត។

import { useState } from 'react';

export default function App() {
  const [count, setCount] = useState(0);

  function handleClick() {
    setCount(count + 1);
  }

  return (
    <>
      <Counter count={count} onClick={handleClick} />
      <Counter count={count} onClick={handleClick} />
    </>
  );
}

function Counter({ count, onClick }) {
  return <button onClick={onClick}>Count: {count}</button>;
}
ចំណុចបង្រៀន: State មួយនៅ parent → child ច្រើនទទួល data ដូចគ្នា → UI sync គ្នា។

Rules of Hooks

Hooks ចាប់ផ្តើមដោយ use។ ត្រូវ call នៅ top level ប៉ុណ្ណោះ — ហាមនៅ loops, conditions, nested functions។

✅ ត្រូវ 
function Profile() {
  const [name, setName] = useState('');
  return <input value={name} onChange={e => setName(e.target.value)} />;
}
❌ ខុស — Hook ក្នុង condition 
function Profile({ isAdmin }) {
  if (isAdmin) {
    const [role, setRole] = useState('admin'); // ❌
  }
}

useEffect លម្អិតសម្រាប់បង្រៀន

useEffect(setup, dependencies?) — sync component ជាមួយ external system។ Effect run បន្ទាប់ពី rendering។

useEffect(() => {
  // setup — start synchronizing
  return () => {
    // cleanup — stop synchronizing
  };
}, [dependencies]);
External SystemExample
Browser APIwindow.addEventListener
TimersetInterval, setTimeout
Networkfetch data
Third-party librarychart, map library

Dependency array:

useEffect(fn) run after every render
useEffect(fn, []) run after first mount only
useEffect(fn, [value]) run when value changes
❌ ខុស — Effect ដែលមិនចាំបាច់ 
function FullName({ firstName, lastName }) {
  const [fullName, setFullName] = useState('');
  useEffect(() => {
    setFullName(firstName + ' ' + lastName); // ❌ unnecessary
  }, [firstName, lastName]);
  return <p>{fullName}</p>;
}
✅ ត្រូវ — calculate ក្នុង render 
function FullName({ firstName, lastName }) {
  const fullName = firstName + ' ' + lastName;
  return <p>{fullName}</p>;
}

Custom Hooks

Custom Hook គឺ function ចាប់ផ្តើមដោយ use ហើយ combine built-in Hooks ដើម្បី reuse logic។

import { useEffect, useState } from 'react';

function useWindowWidth() {
  const [width, setWidth] = useState(window.innerWidth);

  useEffect(() => {
    function handleResize() {
      setWidth(window.innerWidth);
    }
    window.addEventListener('resize', handleResize);
    return () => window.removeEventListener('resize', handleResize);
  }, []);

  return width;
}

function App() {
  const width = useWindowWidth();
  return <p>Width: {width}</p>;
}
អត្ថប្រយោជន៍
Reuse logic ក្នុង components ច្រើន
កាត់បន្ថយ duplicated code
Component UI ស្អាត និងអានងាយ
បំបែក business logic ចេញពី UI
ងាយ test និង maintain

Zustand

Zustand គឺ small, fast, scalable state management library — Hook-based, no boilerplate, no Context Provider wrap required។

// install
npm install zustand

import { create } from 'zustand';

const useCounterStore = create((set) => ({
  count: 0,
  increase: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));

function Counter() {
  const count   = useCounterStore((s) => s.count);
  const increase = useCounterStore((s) => s.increase);

  return <button onClick={increase}>Count: {count}</button>;
}

Zustand Middleware

persist — រក្សាទុក state ក្នុង localStorage / AsyncStorage

import { create } from 'zustand';
import { persist } from 'zustand/middleware';

const useAuthStore = create(
  persist(
    (set) => ({
      token: null,
      setToken: (token) => set({ token }),
      logout: () => set({ token: null }),
    }),
    { name: 'auth-storage' }
  )
);

devtools — debug ជាមួយ Redux DevTools

import { devtools } from 'zustand/middleware';

const useStore = create(
  devtools((set) => ({
    count: 0,
    increase: () => set((s) => ({ count: s.count + 1 }), false, 'increase'),
  }))
);

immer — nested state ដោយ syntax ធម្មតា

import { immer } from 'zustand/middleware/immer';

const useCartStore = create(
  immer((set) => ({
    items: [],
    addItem: (item) =>
      set((state) => {
        state.items.push(item); // mutable style, immutable result
      }),
  }))
);
