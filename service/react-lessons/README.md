## 🚀 របៀបចាប់ផ្តើម

### 1. Install Node.js
ទាញយក Node.js ពី [nodejs.org](https://nodejs.org) (កំណែ LTS)

### 2. បង្កើតគម្រោង React ដំបូង
```bash
npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev
```

### 3. បើក browser
ចូលទៅ `http://localhost:5173`

## 📖 របៀបប្រើវគ្គសិក្សានេះ

1. **អានតាមលំដាប់** - ចាប់ពីមេរៀនទី ០១ ទៅទី ១៣
2. **សរសេរកូដតាម** - កុំគ្រាន់តែអាន ត្រូវសាកល្បងសរសេរ
3. **ធ្វើលំហាត់** - រាល់មេរៀនមានលំហាត់
4. **ធ្វើគម្រោង** - បន្ទាប់ពីមេរៀន ៧ អ្នកអាចចាប់ផ្តើម Todo App បាន

## 💡 គន្លឹះសម្រាប់អ្នកសិក្សា

✅ **សរសេរកូដម្តងទៀត** - កុំ copy/paste តែម្នាក់ឯង  
✅ **កែ​កំហុសខ្លួនឯង** - ការកែ bug ជួយឱ្យអ្នកយល់ច្បាស់  
✅ **សួរសំណួរ** - ជាប់ trouble? ស្រាវជ្រាវ Google ឬ ChatGPT  
✅ **ធ្វើគម្រោងតូចៗ** - រៀន 30% + ធ្វើ 70%  
✅ **ស្ងាត់ៗ ៣០ នាទី/ថ្ងៃ** ល្អជាង ៣ ម៉ោងមួយដង
